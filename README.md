# 招聘信息整理助手（西电就业网 · 线下宣讲会）

> 一个可增量更新的校园线下宣讲会信息整理工具：自动抓取 **西安电子科技大学就业信息网** 的线下宣讲计划，深入每个宣讲详情页提取「宣讲干什么、有没有笔试/面试机会、招聘哪些岗位」，按岗位类别归类整理成 Excel，并按笔试面试机会给出参会推荐。

面向秋招/春招的求职场景：**不用每天刷网页，一条命令拿到未来 N 天的宣讲计划 + 岗位 + 笔试面试机会 + 推荐清单。**

## ✨ 功能特性

- **自动抓取线下宣讲计划**：抓取 job.xidian.edu.cn 线下宣讲会列表（按举办时间升序，可配置未来 N 天范围），自动翻页
- **详情页深度解析**：进入每场宣讲详情页，提取
  - 单位行业 / 性质 / 规模
  - 宣讲详情正文（公司介绍、环节安排、宣讲具体干什么）
  - 职位列表（岗位名 / 薪资 / 城市 / 性质 / 学历 / 需求专业）
- **笔试面试机会识别**：基于标题 + 宣讲正文关键词规则，自动识别「现场笔试/面试、宣讲后安排、仅投递简历、未提及」，并保留**判断依据原文**供人工复核
- **岗位类别分类**：按职位名称自动归类（算法/AI、数据、芯片/硬件、软件开发、通信/网络、产品/设计、运营/市场/销售、职能/管理、制造/供应链、其他）
- **简历驱动推荐**：本地解析简历（PDF/TXT/MD，`resume/resume.pdf`）提取 专业/技能/意向岗位，与每场宣讲的职位需求专业、职位名、岗位类别做匹配打分；推荐理由与新增「简历命中」列给出**具体命中点**（如 `专业:计算机、技能:大模型`），全程本地规则、零大模型调用
- **增量更新**：按宣讲会 id 去重合并——新场次标记「新增」、变更场次标记「更新」、历史已结束场次标记「已结束」保留，重复运行不丢失历史
- **Excel 多表交付**：宣讲会明细 / 岗位明细 / 分类汇总 / 推荐清单 / 数据说明，带样式与筛选
- **规则透明可复核**：所有分类与推荐结论均可追溯到关键词规则与原文依据

## 🛠️ 技术栈

Python 3.10+ · requests · BeautifulSoup4(lxml) · pandas · openpyxl · pypdf（简历解析）

## 🚀 快速开始

```bash
pip install -r requirements.txt
python main.py                  # 默认抓未来14天线下宣讲，增量更新 output/西电线下宣讲会信息汇总.xlsx
python main.py --horizon 30     # 抓未来30天
python main.py --dump-json raw.json   # 同时导出原始数据JSON
python main.py --from-json raw.json   # 用缓存JSON重建Excel（跳过抓取，秒出）
python main.py --resume ./my_resume.pdf   # 指定简历文件（默认 resume/resume.pdf，支持 PDF/TXT/MD）
```

### Windows 一键运行（推荐）

1. 把整个项目文件夹放到目标目录（例如 `D:\招聘信息`）
2. 双击 **`install_and_run.bat`** —— 脚本自动检测 Python；未安装时会尝试用 winget 自动装 Python 3.12，然后自动建虚拟环境、装依赖并运行抓取
3. 以后再次更新，双击 **`run.bat`** 即可（增量更新，历史数据不丢）

> 输出 Excel 生成在 `output\西电线下宣讲会信息汇总.xlsx`。
> 若系统无 winget（Win10 1809 以下）且未装 Python，请手动安装 Python 3.10+（勾选 *Add Python to PATH*）后重试。

## 🧠 核心设计

### 站点防爬机制还原
该站点列表页与详情页正文以 `base64 + zlib` 压缩后内嵌在页面脚本中，由前端 JS 调用 `Base64.decode(unzip("...").substr(n)).substr(m)` 还原。本工具在 Python 端按相同逻辑还原（`crawler.decode_embedded` / `decode_detail_blocks`），不依赖浏览器渲染。

### 增量更新
```
旧表(历史) ──┐
             ├─ 按宣讲会id合并 ──► 新增/更新/已结束 状态标记 ──► 写回Excel
本次抓取 ────┘
```

### 笔试面试机会识别（规则示例）
- 标题/正文含「现场笔试 / 现场面试 / 宣讲后即可安排面试」→ **现场笔试/面试**
- 正文含「笔试 / 面试」安排表述 → **宣讲后安排**
- 仅含「投递简历 / 简历筛选 / 测评」→ **仅投递**
- 均无 → **未提及**

### 推荐度
`机会等级 × 简历画像匹配`。简历解析（`resume_parser.py`，本地规则）提取：
- **专业**：教育背景中的专业关键词（计算机、软件工程…）
- **技能**：技能词典 + 「技术栈：」行提取（大模型、Agent、RAG、Python、PyTorch、Java…）
- **意向岗位**：求职意向行（如「大模型应用算法」）

匹配维度：简历专业 vs 职位「需求专业」/单位行业；简历技能 vs 职位名称；意向岗位 vs 职位名/岗位类别。
命中点写入「推荐理由」与新增「简历命中」列；未配置简历时回退 `config.py` 的 `USER_MAJORS` 规则。

## 📁 目录结构

```
job-assistant/
├── main.py           # CLI入口：抓取→增量合并→Excel→总结
├── crawler.py        # 列表页/详情页抓取与解析（含压缩内容还原）
├── classifier.py     # 岗位分类 + 笔试面试机会识别 + 简历匹配推荐
├── resume_parser.py  # 简历解析（专业/技能/意向岗位，本地规则）
├── storage.py        # Excel读写 + 增量更新
├── config.py         # 抓取范围/输出路径/简历路径/专业背景等配置
├── requirements.txt
├── resume/           # 简历文件（默认 resume/resume.pdf，可替换）
├── output/           # 生成的Excel（gitignore）
└── data/             # 抓取缓存（gitignore）
```

## ⚠️ 注意事项

1. 请遵守目标站点使用条款，工具内置请求间隔与重试，抓取频率可控
2. 详情页联系电话/邮箱为站点登录后可见，抓取结果为掩码
3. 部分单位详情正文为空或更新滞后，请以宣讲现场为准
4. 本工具为求职信息整理用途，仅抓取公开页面数据
